Install the `sikemux` command from **Settings → CLI**.

```text
USAGE:
  sikemux open [--wait] [--project DIR] <PATH[:LINE[:COLUMN]]>...
  sikemux <PATH[:LINE[:COLUMN]]>...
  sikemux status
  sikemux doctor
  sikemux tool METHOD [JSON_PARAMS]
  sikemux --version

OPTIONS:
  -w, --wait         Wait until every opened file tab is closed
  -p, --project DIR  Route unowned files into this project
  -h, --help         Print help
  -V, --version      Print version

LINE and COLUMN are one-based. Existing directories open as projects.
```

As `$EDITOR`, the `sikemux-editor` name waits until the file is closed:

```bash
EDITOR=sikemux-editor git commit
```
