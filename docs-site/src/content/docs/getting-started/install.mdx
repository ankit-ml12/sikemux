---
title: Install
description: "Install Sikemux on a Mac or on Linux, or just its core on a server."
---

## One line

```bash
curl -fsSL https://sikemux.com/install | sh
```

On a Mac this puts Sikemux in `/Applications`. On x86_64 Linux it installs the `.deb` or `.rpm`, or the AppImage in `~/Applications`.

For the nightly build, set the channel before `sh`:

```bash
curl -fsSL https://sikemux.com/install | SIKEMUX_CHANNEL=nightly sh
```

## On a server

A Linux machine with no screen, such as a VPS or a spare box, can run just the core, which keeps agents working with nobody watching:

```bash
curl -fsSL https://sikemux.com/install | SIKEMUX_CHANNEL=nightly sh -s -- --host
```

It works on x86_64 and arm64 and needs no WebKit. The `sikemux` command goes in `/usr/local/bin`, or in `~/.local/bin` when you are not root. With systemd, the core then starts at boot and restarts if it crashes. Last, the installer prints a code: approve it at app.sikemux.com or in Sikemux on your phone to add the host to your account.

Later:

- `sikemux core status` shows whether the core runs and which account it is on.
- `sikemux core sign-in` signs the host in, if you skipped it.
- Running the same line again updates the core. A core already running keeps the old version until `systemctl --user restart com.nodelike.sikemux.core`.

## Download

The latest `.dmg` is on [sikemux.com](https://sikemux.com) and on [GitHub Releases](https://github.com/nodelike/sikemux/releases/latest). It is about 16 MB and needs macOS 11 or later on Apple Silicon.

On x86_64 Linux the same release has a `.deb`, an `.rpm` and an `.AppImage`:

```bash
sudo apt install ./Sikemux_<version>_amd64.deb      # Debian, Ubuntu
sudo dnf install ./Sikemux-<version>-1.x86_64.rpm   # Fedora
chmod +x Sikemux_<version>_amd64.AppImage           # any other distribution
```
