title: Updates
description: "Stable and nightly channels, and how Sikemux updates itself."
---

On a Mac, and from the AppImage on Linux, Sikemux keeps itself up to date. Choose how new in **Settings → About → Updates**:

| Channel | What you get |
|---|---|
| **Stable** | The latest signed release |
| **Nightly** | The newest signed build, prerelease or stable |

When an update is out, the foot of the left rail says so, then shows how its download and install are going. Click it for the release's notes and **Install**.

**Check now** looks for an update straight away. While you are offline, a check you start says so and tries again later.

If Sikemux's servers stop working with the version you have, **Update Sikemux** covers the window. Remote access and your account stay off until you update; you can also quit from there.

## Linux

The AppImage updates itself like the Mac app.

The `.deb` and `.rpm` are updated by the installer that put them in place. When a new release is out, **Settings → About** shows it with **Copy command**. Run the copied line in a terminal:

```bash
curl -fsSL https://sikemux.com/install | sh -s -- --app
```

On the nightly channel, the line sets `SIKEMUX_CHANNEL=nightly` before `sh`.
